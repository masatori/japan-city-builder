# 日本シティービルダー - ゲームデザインドキュメント

## 📋 プロジェクト概要

**タイトル**: Japan City Builder（日本シティービルダー）

**ジャンル**: シティービルディング / シミュレーション

**対象プラットフォーム**: PC（Windows/Mac/Linux）

**開発言語**: Python（Pygame または Godot Engine）

**プレイヤー向け説明**: 日本の地形を舞台に、駅や空港、ビル街などのインフラを建設し、日本の経済・交通を発展させるシミュレーションゲーム

---

## 🎯 ゲームの目的・コンセプト

### ゲーム目標
- プレイヤーが市長・都市計画者となり、日本国内に都市インフラを構築
- 人口増加、経済成長、交通網の最適化を目指す
- リソース管理と長期戦略が必要

### コンセプト
- **Cities: Skylines** の日本版
- リアルな日本の地形・都市配置
- 実際の日本の地名・駅名・空港を使用
- 経済・人口・交通のシミュレーション

---

## 🎮 ゲームメカニクス

### コアシステム

#### 1. **マップ・地形システム**
- 日本全国を俯瞰図で表示
- グリッドベースのタイル配置
- 地形種別：
  - 平地（建設可能）
  - 山岳地帯（限定建設）
  - 河川（橋建設で横断可能）
  - 海岸（港湾建設）
  - 既存都市（拡張可能）

#### 2. **建物・インフラシステム**
主要な建築物カテゴリ：

**交通インフラ**
- 🚉 駅（鉄道ネットワーク）
- ✈️ 空港（国内線・国際線）
- 🛣️ 道路（高速道路、一般道）
- 🌉 橋・トンネル

**経済施設**
- 🏢 オフィスビル（雇用創出）
- 🏭 工業地帯（製造業）
- 🏬 商業地区（商業）
- 🏠 住宅地（人口増加）

**公共施設**
- 🏫 学校・大学（教育）
- 🏥 病院（医療）
- 🚓 警察署（治安）
- 🚒 消防署（防火）
- 🏛️ 庁舎（行政）

**観光・娯楽**
- 🎢 テーマパーク
- ⛩️ 神社仏閣
- 🗼 観光塔
- 🏖️ リゾート施設

#### 3. **リソース管理**
```
主要リソース：
├── 💰 資金（予算）
├── 👥 人口
├── 💼 労働力
├── ⚡ 電力
├── 💧 水道
├── 🗑️ ゴミ処理
└── 🚌 交通容量
```

**資金フロー**
- 収入：税金（住民税、企業税、観光収入）
- 支出：建設費、維持費、サービス運営費

#### 4. **人口・雇用システム**
- 住宅地の建設 → 人口増加
- 雇用機会（工業・商業・公共）増加 → 失業率低下
- 教育・医療の質 → 人口満足度向上
- 満足度低下 → 人口流出

#### 5. **交通システム**
- 🚂 鉄道ネットワーク：駅間の接続で運行開始
- 🚌 バス路線：道路に沿って自動配置
- 🚗 自動車交通：道路の混雑管理
- ✈️ 航空：空港間の国内線・国際線

**交通指標**
- 混雑度（渋滞状況）
- 移動時間
- 輸送力

#### 6. **経済・産業システム**
- **産業チェーン**：
  - 一次産業（農業・漁業）→ 二次産業（製造）→ 三次産業（商業・サービス）
  - 観光産業（外国人観光客増加による収入）
  
- **企業エコシステム**：
  - 本社企業は他の地域に支社・工場を建設
  - 企業規模拡大による人口・雇用増

#### 7. **イベント・シナリオ**
- 🌍 自然災害（地震、洪水、台風）
  - インフラ被害
  - 災害復旧費用
  
- 💼 経済イベント
  - 好景気・不景気
  - 大企業の進出・撤退
  
- 🎭 特別イベント
  - オリンピック招致
  - 万博誘致
  - 映画・ドラマ撮影地誘致

## 📊 ゲームの進行フロー

### ゲームサイクル
```
1. ゲーム開始 → 初期資金と空の日本地図
2. 計画フェーズ
   ├─ インフラを配置
   ├─ 建物を建設
   └─ 予算配分
3. シミュレーションフェーズ
   ├─ 時間経過（月単位）
   ├─ 人口・経済シミュレーション実行
   └─ イベント発生判定
4. 結果フェーズ
   ├─ 収支決算
   ├─ 人口・満足度更新
   ├─ 統計情報表示
   └─ 次のサイクルへ
```

### ゲーム進行速度
- ゲーム内時間：1ターン = 1ヶ月
- リアルタイム進行：プレイヤーが速度調整可能
  - ⏸️ 一時停止
  - ⏯️ 通常速度
  - ⏩ 高速
  - ⏭️ 超高速

## 🎯 ゲームモード

### 1. **フリープレイ**
- 制限なしで自由に都市構築
- 目標なし、プレイヤー自身で目標設定

### 2. **シナリオモード**
各シナリオで異なるチャレンジ：

| シナリオ | 舞台 | 初期状態 | 目標 |
|---------|------|---------|------|
| 東京再開発 | 東京 | 既存都市 | 人口1,000万達成 |
| 大阪経済特区 | 大阪 | 荒廃地 | 企業誘致100社 |
| 北海道開拓 | 北海道 | 未開発 | 持続可能な経済構築 |
| 瀬戸内海交通網 | 瀬戸内 | 分断状態 | 鉄道・空港で統合 |

### 3. **チャレンジモード**
- 期限内に目標達成
- 予算制限あり
- スコアランキング

## 📈 ゲームバランス

### 難易度設定
| 難易度 | 特性 |
|--------|------|
| **イージー** | 高い初期資金、低い運営費、イベント少なめ |
| **ノーマル** | バランス型 |
| **ハード** | 低い初期資金、高い運営費、頻繁なイベント |
| **サバイバル** | 非常に厳しい条件、資金不足の常態 |

### 経済バランス
- 建設費 vs 収益性のバランス
- 短期収入 vs 長期投資のトレードオフ
- 保守費用の現実的な算出

## 🎓 技術スタック候補

### オプション1：Pygame（Python）
```
✅ メリット：
- Pythonの学習も兼ねられる
- シンプルな構造
- コミュニティが豊富

❌ デメリット：
- 大規模ゲーム向けではない
- グラフィック品質に限界
```

### オプション2：Godot Engine（GDScript/C#）
```
✅ メリット：
- 無料・オープンソース
- 2D/3D両対応
- パフォーマンス良好
- マルチプラットフォーム対応容易

❌ デメリット：
- 学習コストがやや高い
- エコシステムが小さめ
```

### オプション3：Unity + C#
```
✅ メリット：
- 業界標準
- リソース豊富
- 3D対応

❌ デメリット：
- エンジン自体が重い
- シティビル向けではない側面
```

**推奨**: **Godot Engine** or **Pygame**（スコープに応じて）

## 📝 まとめ

このゲームは、**Cities: Skylines** の日本版として、プレイヤーが日本の各地域で都市を構築し、経済を成長させることを目指す。リアルな日本の地形・地名を使用しながら、シンプルながら奥深いシミュレーション体験を提供する。

段階的な開発で、段階的に機能を追加し、プロトタイプから完成版へ向けて進化させていく。
